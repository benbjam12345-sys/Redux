# Redux

## Simplified Quest 3S setup

The REDUX Android app now uses a single setup screen:

1. Open Wireless Debugging.
2. Pair once using the temporary pairing port and six-digit code.
3. Connect using the separate port shown on the main Wireless Debugging screen.
4. After connecting, use the simple Quick Actions section.

The in-game native menu library is a separate experimental component and is not installed by connecting ADB.
